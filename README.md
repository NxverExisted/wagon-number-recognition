# Разметка номерных частей деталей вагонов

## Описание проекта

Проект предназначен для автоматического обнаружения номерных частей железнодорожных вагонов на фотографиях, их выделения и последующего распознавания цифр.

Для обнаружения и сегментации номерных областей используется нейронная сеть YOLO11n-Seg, а для распознавания цифр — EasyOCR.

## Используемые технологии

- Python 3.12
- Ultralytics YOLO 11
- YOLO Segmentation
- EasyOCR
- OpenCV
- NumPy
- PyTorch

## Датасет

Для обучения модели подготовлен датасет из 312 изображений:

| Выборка | Количество изображений |
|---|---:|
| Обучающая (Train) | 249 |
| Валидационная (Val) | 63 |
| **Всего** | **312** |

## Обученная модель

В папке `models` находятся:

- `best.pt` — веса модели с лучшими результатами обучения.
- `last.pt` — веса модели после последней эпохи обучения.
- `yolo11n-seg.pt` — исходные веса предобученной модели YOLO11n-Seg.
